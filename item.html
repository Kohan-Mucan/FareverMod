Farever Item Lookup

Find Farever weapons, armor, gear and loot sources with FareverMod.

Item sources from Farever’s game data

FareverMod’s item and gear views connect in-game entries with their acquisition sources. Browse gear and items, inspect farm rows, and use the planning tools for upgrades, enchantments and other build materials.

Item, mob and acquisition information shown in the companion comes from Farever’s own files and loot tables. The app describes where items can be acquired; actual drops remain server-authoritative.

FareverMod is a Windows companion app. This page describes its lookup features; it is not an interactive web database.
