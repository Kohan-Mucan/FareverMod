Farever Codex

Explore Farever’s bestiary and collectible entries with the FareverMod codex.

Units by zone, collections by type

The Codex presents unit cards grouped by zone, with search and filters to help browse the game’s entries. Its collection view covers pets, mounts, gliders, chests and orbs.

Collection cards include visible and hidden entries, plus a Missing filter that can plot unowned entries on the in-app world map. The entries are sourced from Farever’s own game data.

FareverMod’s codex is part of the Windows companion app; it does not provide a live web database.
