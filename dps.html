Farever DPS Meter

Measure combat damage in Farever with the FareverMod live meter and encounter analysis.

Live meters and encounter breakdowns

The live meter ranks group damage from Farever’s per-hit combat events. Encounter Analysis adds a timeline, player rankings and per-skill totals, with segments for bosses, trash, adds or the overall fight. Saved encounters can be reviewed alongside personal-best run history.

Choose a capture mode in the app: the default hot injector, a drop-in proxy DLL, or a DLL-free memory reader. The meter uses combat events—not health polling or HP differences—and remains empty until real events arrive.

Capture modes matter: the two DLL modes use a game hook to export combat events. The memory-reader mode is the strictly DLL-free option. As with any game hook, DLL-based modes carry normal caveats.
